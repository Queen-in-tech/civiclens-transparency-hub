# UI/UX Design Skill & Standards

## Core Philosophy
- **No Generic AI Aesthetics:** Never use purple/indigo gradients on white backgrounds, generic 3-column feature grids, floating glowing blobs, or default SaaS templates.
- **Intentional Direction:** Commit to a bold, cohesive aesthetic (e.g., Swiss editorial minimalism, high-contrast brutalist utility, or warm tactile craft) before writing any code.

## Typography & Color
- **Fonts:** Avoid Inter, Roboto, and Arial. Pair a distinctive display font (e.g., Instrument Serif, Space Grotesk, Syne, or Plus Jakarta Sans) with a clean body font and a crisp monospace font (JetBrains Mono) for data/numbers.
- **Color Palette:** Stick to a strict 60-30-10 rule. Use rich off-blacks (#0A0A0C) or warm off-whites (#F8F7F4) instead of harsh pure #000000 or #FFFFFF. Use one sharp, purposeful accent color.

## Layout & Components
- **Whitespace & Hierarchy:** Use generous padding and asymmetrical layouts where appropriate. Let content breathe rather than boxing every element inside a bordered card.
- **Micro-interactions:** Use subtle, crisp transitions (`transition-all duration-200 ease-out`) and clear hover/focus states rather than bouncy, over-the-top animations.
- **Real Data:** Always populate UI components with realistic, domain-specific copy and numbers—never use "Lorem ipsum" or "John Doe".
